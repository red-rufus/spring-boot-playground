# Spring Boot Playground

A collection of Spring Boot learning projects exploring backend technologies.

## Projects

| Project | Concepts |
|---|---|
| spring-boot-graphql | Spring GraphQL, JPA, H2 |
| spring-boot-webflux | Spring Webflux, R2DBC, H2 |
| spring-boot-kafka | Spring Web, Spring Kafka |
| spring-boot-event-sourcing | Spring Web, Spring Kafka |

- Spring Boot

- webflux

- Kafka
